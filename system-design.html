System Design

From architectural choices to monitoring, here's a concise yet deep guide.

High-Level Design (HLD)

1) Architectural Patterns

Monolithic

  • ✅ Simple deploys, easy dev loop
  • ❌ Scalability & coupling issues
  • Use when: small teams, MVPs, strong cohesion

Microservices

  • ✅ Independent scale & release
  • ❌ Operational complexity
  • Use when: bounded contexts & high scale

Event-Driven

  • ✅ Async, decoupled
  • ❌ Debugging & consistency challenges
  • Use when: high throughput, eventual consistency ok

Serverless

  • ✅ No infra mgmt, scale-to-zero
  • ❌ Cold starts, vendor lock-in
  • Use when: bursty workloads, glue code
2) Core Components

API Gateway

Routing, authN/Z, rate limits, request shaping.

Load Balancer

L4/L7, health checks, sticky sessions.

Database

SQL vs NoSQL, CAP, indexing, sharding.

Cache

Redis/Memcached; TTLs, eviction, cache-aside/write-through.

Queue/Stream

Kafka/RabbitMQ; backpressure, retries, DLQs.

Storage

Object vs block; lifecycle, encryption, costs.

3) Scalability, Reliability & Performance
  • Horizontal scaling, consistent hashing, partitioning
  • Replication, quorum, circuit breakers, bulkheads
  • Latency budgets, caching strategies, CDNs
Rule: Optimize read paths with caches/CDN; write paths with partitioning.
4) Security & Deployment

Security

  • OAuth2/OIDC, JWT, mTLS
  • Input validation, WAF, threat modeling

CI/CD

  • Blue/Green, Canary, feature flags
  • Rollbacks, migrations, smoke tests

Observability

  • Metrics, logs, traces
  • SLIs/SLOs, error budgets

Low-Level Design (LLD)

1) OOD & Design Principles

SOLID

Single responsibility, Open/closed, Liskov, Interface segregation, Dependency inversion.

Patterns

Creational (Factory, Builder), Structural (Adapter, Decorator), Behavioral (Strategy, Observer).

UML

Class, Sequence, Activity diagrams for communication.

2) Data & DB Design
  • Schema normalization vs denormalization
  • Transactions: ACID vs BASE, isolation levels
  • Indexes: B-Tree, Hash; query optimization
3) Concurrency & Multithreading
  • Threads, locks, deadlock avoidance
  • Async patterns, futures/promises
  • Concurrent collections, immutability
4) API Design
  • OpenAPI/Swagger, resource modeling
  • Versioning, pagination, rate limiting
  • Error contracts, idempotency keys
5) Testing & Perf
  • Unit/Integration/Contract tests
  • Profiling, memory management, refactoring
